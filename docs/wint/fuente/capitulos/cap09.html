Casi nada de lo que WINT necesita hay que inventarlo: Windows trae las acciones de energía, Python tiene bibliotecas maduras para rastrear y guardar, y hay buenos proyectos para mostrar datos y mandar avisos. Lo que no existe es la pieza que las une con reglas propias y sin conversación. Este capítulo reúne en un solo lugar lo que conviene usar, lo que conviene evaluar y lo que conviene evitar.

Los veredictos aplican el criterio de los capítulos anteriores: preferir lo incluido en Windows o en la biblioteca estándar, lo mantenido en 2026, lo que se puede autoalojar y lo de licencia permisiva. Las versiones y fuentes de cada herramienta están citadas en los capítulos 4 a 8; las que solo aparecen aquí se citan en la tabla. Usar es la elección por defecto; Evaluar, una alternativa razonable si la primera no alcanza; Evitar, un riesgo que no compensa.

Un «Google comprimido» sin construir un buscador

La aspiración de un «Google comprimido» se resuelve, en la práctica, con una búsqueda unificada sobre las fuentes propias: catálogos, precios, notas. SQLite trae un índice de texto completo (FTS5) que alcanza para eso dentro del mismo archivo de datos. La puerta de entrada no tiene por qué ser una app propia: un plugin de Flow Launcher o una extensión de Command Palette pueden consultar la API de WINT y mostrar resultados con una tecla. El comportamiento de FTS5 con acentos del español no se verificó en esta investigación sin verificar.
