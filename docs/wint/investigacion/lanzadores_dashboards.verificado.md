## Correcciones clave (lo que cambia el informe)

1. SDK de extensiones de Command Palette (H2): NO son dos paquetes NuGet. Hay un solo paquete, Microsoft.CommandPalette.Extensions, que incluye tanto el API WinRT (winmd y DLL nativa) como el ensamblado Microsoft.CommandPalette.Extensions.Toolkit.dll; en nuget.org no existe un paquete aparte llamado Microsoft.CommandPalette.Extensions.Toolkit (devuelve 404). La última versión es 0.12.260812002 (MIT, destino net8.0-windows10.0.19041), todavía 0.x, es decir, sin versión 1.0 y con cambios incompatibles posibles, lo que coincide con el aviso "preview" del README del módulo.
2. PowerToys v0.101.2362.0 (H4 y tabla): la afirmación "no marcada Latest" es falsa. La página de releases de GitHub la muestra con la etiqueta "Latest" (25 de agosto de 2026) y /releases/latest resuelve a ella; lo que sí tiene es una advertencia en sus notas: "We're working through an issue with the update rollout, so this PowerToys release may take a little longer than usual to reach everyone". Las siete previews posteriores (de v0.101.2572.0 del 15 de septiembre a v0.101.2781.0 del 7 de octubre de 2026) sí son pre-releases.
3. Fechas "ms.date" de la documentación de Microsoft (H1, H3, H4): el formato es mes/día/año (lo prueba "10/28/2025" en creating-an-extension). Por eso overview, extensibility-overview y extension-development dicen 04/10/2026, que es el 10 de abril de 2026 (no el 4 de octubre); publish-extension y extension-gallery dicen 06/04/2026, que es el 4 de junio de 2026 (no el 6 de abril); dock.md dice 03/09/2026, que es el 9 de marzo de 2026. La fecha de la documentación no equivale a la fecha en que salió una función.
4. Cifras de H1 y de la fila de PowerToys Run: la tabla "What you can do" de la documentación de Command Palette tiene 18 filas (no 16), y la tabla de comandos de activación de PowerToys Run lista 18 plugins (no "unos 15").
5. Requisito de sistema de Command Palette (H2): la guía de creación de extensiones exige Windows 11, pero el manifiesto de la app de CmdPal en el repositorio de PowerToys declara MinVersion 10.0.19041.0 (Windows 10 versión 2004 o posterior). El requisito de Windows 11 es del desarrollo de extensiones, no necesariamente del uso.
6. Nombre del comando para crear extensiones (H2): las fuentes de Microsoft no coinciden. creating-an-extension.md (ms.date 10/28/2025) dice `Create a new extension`; extension-development.md y el README del módulo dicen `Create extension`. En el informe conviene escribir "el comando de crear extensión (Create extension / Create a new extension)".
7. SDK de plugins de Wox (H7): el paquete de npm no se llama `wox-plugin` (npm responde "Not found") sino `@wox-launcher/wox-plugin` (última 0.0.141). En PyPI el paquete es `wox-plugin` (0.0.89, subido el 2026-09-24); `wox_plugin` es el nombre de importación y PyPI lo normaliza al mismo paquete.
8. Raycast (H8 y tabla): el changelog de la API termina en 2.5.0 (2026-09-24), pero npm ya publicó @raycast/api 2.6.0 (2026-09-30), 2.6.1 y 2.6.2 (2026-10-02) y 2.6.3 (2026-10-05). La última versión del paquete de la API es 2.6.3, no 2.5.0. El motor requerido sigue siendo Node >=22.22.2. Precio y estado (beta o general) de Raycast para Windows siguen sin poder verificarse.
9. Tailscale (H21 y tabla): la discrepancia v1.102.5 frente a v1.104.0 se explica. v1.102.5 es la última Release publicada en GitHub (29 de septiembre de 2026, 18:47 UTC; su tag es del 24 de septiembre). v1.104.0 y v1.105.0-pre son solo tags creados el 30 de septiembre de 2026 (proxy.golang.org: 18:46 y 19:03 UTC), sin Release publicada al 7 de octubre. Además, el README de Tailscale aclara que los clientes de macOS, iOS y Windows añaden "small GUI wrappers" que "on non-open source platforms are themselves not open source": el cliente de Windows de la persona no es BSD-3-Clause completo; lo es el núcleo (tailscaled y la CLI) y el repositorio tailscale-android. Precio y plan gratuito siguen sin verificarse.
10. Smartspacer (H18 y tabla): "sin root" es cierto, pero para mejorar el At a Glance integrado de los Pixel exige Shizuku (README: "requires Shizuku"); el widget funciona con cualquier launcher. Mínimo de Android: minSdk 29 (Android 10) según su build.gradle.
11. Dashy (H13): el README no dice "mínimo 1 GB de RAM y 1 GB de disco": dice que 1 GB de memoria "should be more than enough" y que 1 GB de disco "should be sufficient". La página de despliegue indica que el servidor Node usa unos 80 a 120 MB en reposo, 256 MB es cómodo y la imagen ocupa unos 250 MB. Node requerido (package.json): ^22.22.2 o ^24.15.0 o >=26; el README recomienda la LTS 24.x. Última versión: v4.7.18 (2026-10-07T08:30Z), no v4.7.17.
12. Heimdall (H13): composer.json de la rama por defecto (2.x) pide PHP ^8.4 y laravel/framework ^13.0, no Laravel 11. Es MIT, versión v2.8.3 (2026-09-05).
13. Home Assistant (H14): el puerto por defecto de la API REST es 80 en Home Assistant OS y 8123 en las demás instalaciones, no siempre 8123. La versión 2026.9.4 (27 de septiembre) sigue siendo la estable; ya hay betas 2026.10.0b1 a b4 (5 al 7 de octubre de 2026).
14. Olauncher (H17 y tabla): el README no dice que "Pro Launcher" sea de pago; dice solo "Pro version of Olauncher with extra features like widgets, weather, folders, etc.". Sí consta la versión del código: v6.9.17 (versionCode 113 en app/build.gradle).
15. Notificaciones con acciones (H22, matiz de diseño): la acción `http` de ntfy envía la petición "when the action button is tapped" (el ejemplo oficial usa una URL de LAN, https://api.mygarage.lan/close), es decir, la dispara la app del teléfono. Si el botón "silenciar este producto" debe llegar a la API de WINT en 127.0.0.1 de la PC, esa URL no sirve desde el teléfono; hay que usar una dirección alcanzable (por ejemplo la IP de Tailscale). Esto es una inferencia mía a partir de la documentación, no un dato literal.
16. SQLite FTS5 (H23 y tabla): pasa de "no verificado, confianza baja" a CONFIRMADO. Prueba local con SQLite 3.45.1 (compile option ENABLE_FTS5): se creó una tabla virtual fts5 con columnas UNINDEXED y se consultó con MATCH y bm25(). El código fuente (sqlite/sqlite, ext/fts5/fts5.h) lleva la bendición de dominio público. Queda por probar que el Python de Windows de la persona traiga FTS5 compilado (comprobar con `select * from pragma_compile_options`).
17. Versiones nuevas que llenan huecos de la tabla: YunoHost tiene la serie 13.0.x (13.0.8, 2026-09-19, pre-release) además de debian/12.1.41.2 (3 de septiembre de 2026, marcada Latest; año confirmado por el feed); KDE Connect: kdeconnect-kde v26.08.1 (tag del 10 de septiembre de 2026) y kdeconnect-android v1.35.17 (25 de septiembre de 2026, minSdk 23 = Android 6.0); Headscale v0.29.4 (2026-09-23); Meilisearch v1.54.3 (2026-10-01); licencias: Lawnchair Apache-2.0, Termux GPLv3 (solo v3), ES de voidtools MIT.
